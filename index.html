SCNHS Attendance Portal

Student QR attendance access

Welcome

Use the scanner to read a student's SCNHS attendance QR code. After a valid QR code is scanned, the student's attendance page will open.

Open QR Scanner

How to use

  1. Open this website using a phone with a camera.
  2. Tap Open QR Scanner.
  3. Allow camera access when your browser asks.
  4. Point the camera at the student's QR code.
  5. When the QR is recognized, tap the button to open the attendance page.
Important: The QR code created by the Apps Script QR Manager contains a private student link. Keep each student's QR code confidential.

Camera permission

The scanner requires HTTPS. GitHub Pages provides HTTPS automatically. If camera access is blocked, open the site in your phone's regular browser and allow camera permission in the browser settings.
